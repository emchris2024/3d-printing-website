# 3D Printing Business Website

Static business website hosted on TrueNAS SCALE.

## Infrastructure

- NGINX Docker container managed through Dockge
- Cloudflare Tunnel for public access
- Static HTML, CSS, JavaScript, and images

## Tracked in Git

- `website/html/`
- `website/nginx/default.conf`

## Not tracked

- Cloudflare tokens or environment files
- Customer uploads
- Logs
- Backups
- Database files
- Certificates and private keys
